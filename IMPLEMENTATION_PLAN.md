# VidyaNova implementation plan

1. Use the 1440 × 1000 Figma frames as desktop layout references. The student prototype starts on My learning path, and the faculty dashboard has its own sidebar.
2. Establish a React and TypeScript shell with shared cards, tables, navigation, theme tokens, and role guards.
3. Implement student learning, practice, assessments, coding, progress, placement and profile screens, then add academics, assignments and internships.
4. Connect faculty publishing and evaluation to the student workspace through persistent mock services.
5. Verify static checks, the production build and representative student and faculty flows.
